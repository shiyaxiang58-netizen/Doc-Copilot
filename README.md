# File Processing Assistant

一个面向学生、实习生和职场新人的真实资料学习助手。它可以读取 PDF、网页和文本笔记，通过你配置的 AI 服务生成总结、重点、问答、行动建议和原文引用。

## 启动

1. 安装 Node.js 20 或更高版本。
2. 在项目目录运行 `npm install`。
3. 复制 `.env.example` 为 `.env`，填写：
   - `AI_API_KEY`：AI 服务密钥。
   - `AI_MODEL`：模型名称。
   - `AI_BASE_URL`：兼容 OpenAI Chat Completions 的接口地址。
4. 运行 `npm start`，访问 `http://127.0.0.1:3000`。

在 Codex 桌面环境中，也可以运行 `powershell -ExecutionPolicy Bypass -File .\start.ps1`，脚本会优先使用可用的 Node.js 运行环境。

## 演示流程

1. 新建学习任务并填写名称。
2. 连续添加 PDF、网页链接或文本笔记。
3. 启动真实分析，查看分阶段处理进度。
4. 阅读总结、结构化重点和跨资料知识结构。
5. 完成选择题、简答题和行动清单。
6. 在资料库与复习中心继续学习。

## 主要能力

- 多资料任务与本地历史记录
- 真实 AI 总结、重点提炼和知识结构
- 可切换偏好的重新生成与上一版恢复
- 分屏原文依据和关键句高亮
- 选择题即时反馈与简答题模拟 AI 点评
- 行动清单、资料库和复习中心进度同步
- 学习卡片预览与复制
- 浏览器本地保存、错误恢复和一键重置数据
- 桌面端、平板和移动端响应式布局

## 数据与安全

- API 密钥只保存在服务端 `.env` 中，不会写入前端代码或浏览器存储。
- PDF、网页正文和文本会发送到所配置的 AI 提供商，请勿提交无权处理的敏感资料。
- 网页抓取会拒绝本机和常见内网地址。
- 浏览器会保存分析结果和必要的引用片段，但不保存上传的完整文件；服务端只在内存中保留近期问答上下文，服务重启后会失效。
